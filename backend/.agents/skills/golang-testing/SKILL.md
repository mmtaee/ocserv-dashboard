# Go Testing

Use this skill with `golang` when adding tests, fixing bugs, reviewing Go changes, or verifying completed Go work.

Add focused tests at the repository's established test locations. Format every modified Go file and run the narrowest relevant checks plus broader project checks when practical. Report any check that could not run or did not pass.
